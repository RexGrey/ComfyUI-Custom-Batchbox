# 上传下载安全检查清单

## 图片上传
- [ ] 上传前检查图片解码大小（防止图片炸弹）
- [ ] base64 图片有大小限制（per_image_budget 计算）
- [ ] MIME 类型校验（只允许 image/*）
- [ ] 上传文件名由 hash 生成，不使用原始文件名

## 对象存储安全
- [ ] OSS AK/SK 只在网关或配置文件中，不在学生机环境变量
- [ ] GCS Service Account 只在配置文件中加密存储
- [ ] Files API 使用已有 API Key，不引入额外凭证
- [ ] 上传后的 URL 不包含可逆签名（OSS 公开读配置）

## 下载安全
- [ ] 下载结果图片只从已知 API 响应中获取 URL
- [ ] 不接受用户直接提供的任意下载 URL
- [ ] 下载超时设置合理

## 缓存安全
- [ ] 缓存 DB 中的 URL 不包含敏感参数
- [ ] 预签名 URL（如 GCS）有过期时间
- [ ] Files API URI 有 48h 过期时间，缓存正确处理过期
