## 攻击者画像

| 攻击者 | 能力 | 动机 |
|:-------|:-----|:-----|
| 学生 | 可运行 ComfyUI、读 Z 盘、分析 bat、构造请求 | 好奇、绕过限额、盗用配额 |
| 外部 API | 返回畸形数据、超时、429 限流 | 非恶意但不可控 |
| NAS 故障 | 短暂断连、锁冲突 | 非恶意基础设施故障 |

## 现有防御架构

1. **密钥不落地**：`BATCHBOX_KEY` 运行时环境变量注入
2. **加密存储**：`secrets.yaml` 使用 AES-256-GCM
3. **日志脱敏**：key 尾号 ≤8 字符
4. **模板沙箱**：纯正则替换，无 eval/exec
5. **资源上限**：batch_count≤20, body≤500MB
6. **共享缓存降级**：NAS 不可达时透明降级
